## 1. 사용자 프로필: 현표 (maison_jenflox)

현표는 "옷 추천하는 인플루언서"가 아니라 **혼자 돌리는 1인 커머스 미디어**다.
편집자 1명을 제외한 모든 업무를 본인이 직접 수행한다.

### 채널 포트폴리오

| 채널 | 형태 | 특성 |
|---|---|---|
| 유튜브 '전현표입니다' | 본편 + 쇼츠 | 착장정보·언급 상품을 고정댓글에 정리 |
| 인스타그램 릴스 | 크로스포스팅 | '링크'/'크링' 댓글 유도 → 수동 링크 전달 |
| 스레드 | 실시간 꿀매템 추천 | 텍스트 중심, 발행 빈도 가장 높음 |
| 틱톡 | 크로스포스팅 | |
| 카카오톡 오픈채팅 '꿀매각 아이템 발굴' | 방송형 (관리자만 발언), 2,754명 | 실시간 딜 + "자정까지 쿠폰" 마감 공지. **API 없음** |
| 링크트리 → 노션 | 영상 1편 = 노션 페이지 1개, 40+개 누적 | 절반 이상이 브랜드 협업 콘텐츠 |

### 수익 구조 (= 지켜야 할 계정)

1. **무신사 큐레이터 링크** — 판매 기여 시 최대 10%+ 커미션, 구독자 전용 쿠폰 발행
2. **온더룩 셀렉샵** (jenflox.com) — 샘플·기획전·매달 15일 정산
3. **브랜드 협찬 영상** — 조건 협의(쿠폰·할인율·기간·시딩)는 매번 브랜드사 재량에 맞춤
4. **유튜브 광고 수익**

→ **카카오 계정, 무신사 큐레이터 계정, Meta 계정(인스타/스레드), 유튜브 계정 중 하나라도
정지되면 수익 구조의 축이 무너진다. 이것이 본 프로젝트의 제1 제약조건이다.**

## 2. 업무 해부: 하루/주 단위 6덩어리

| # | 업무 | 빈도 | 성격 |
|---|---|---|---|
| 1 | **딜 소싱·모니터링** — 신상, 할인율, 쿠폰, 랭킹 급상승, 사이즈별 재고 감시. "S부터 품절되네요" 같은 훅은 재고 변화를 직접 지켜본 결과 | 24시간 실시간 | 타이밍 싸움. 폰을 놓을 수 없음 |
| 2 | **큐레이션·카피** — 후보 중 선별(취향+데이터), 한두 줄 훅 작성. '꿀매각디렉터' 브랜드의 실체 | 매일 | 판단 + 창작 |
| 3 | **링크·상품정보 가공** — 색상별 큐레이터 링크 생성, 브랜드/품번/가격/쿠폰을 템플릿으로 정리. **같은 정보를 카톡·스레드·노션·고정댓글·DM에 4~5회 재입력** | 매일 수십 회 | 순수 반복 노동 |
| 4 | **콘텐츠 제작** — 기획, 협찬 제품 수령·착장·촬영, 썸네일·제목·설명란·고정댓글, 쇼츠 재가공 지시 (편집만 외주) | 주 단위 | 사람 고유 영역 + 부속 반복 작업 |
| 5 | **커뮤니티·CS** — '링크' 댓글 응대, 사이즈 질문(168/62 기준), 재입고·쿠폰 문의, 오픈채팅 공지 갱신 | 매일 | 반복 + 신뢰 자산 |
| 6 | **비즈니스·관리** — 협찬 문의·조건 협의, 셀렉샵 운영, 정산 취합(큐레이터/셀렉샵/유튜브), 세금 | 주·월 단위 | 판단 + 취합 노동 |

### 병목 5가지 (자동화의 표적)

- **(a) 24시간 모니터링** — 사람이 기계 역할을 하고 있음
- **(b) 동일 정보 N회 재입력** — 하나의 딜이 4~5개 채널 포맷으로 수동 복제됨
- **(c) 죽은 링크** — 품절·쿠폰 만료 링크가 옛 글/노션에 남아 신뢰를 갉아먹음
- **(d) 성과 데이터 분산** — 큐레이터 센터·셀렉샵·유튜브 스튜디오·IG 인사이트에 흩어져 "뭐가 실제로 팔리는지" 통합 파악 불가
- **(e) 카톡방 API 부재** — 최대 채널(2,754명)이 분석도 자동화도 0

## 3. 자동화 가능성 맵

### A. 프로그램으로 거의 완전 대체 (사람 개입 ≤10%)

| 기능 | 설명 | 제약 |
|---|---|---|
| 딜 레이더 | 무신사 신상·할인·쿠폰·랭킹·재고 변화 수집 → 점수화 → 후보 큐 | 공개 API 없음 → 저빈도 크롤링, 계정 완전 격리 필수 |
| 원클릭 링크·카드 생성기 | 상품 페이지에서 버튼 1회 → 정보 추출 + 큐레이터 링크 + 채널별 포맷 동시 생성 | 크롬 확장, 사람 클릭 기반 (백그라운드 자동화 금지) |
| 노션·링크 허브 자동 생성 | 영상 1편 = 노션 페이지 + 링크 허브 항목 자동 | Notion 공식 API |
| 링크 헬스체크 | 발행된 링크 주기 점검 → 품절/만료 표시·대체 제안 | 저빈도 |
| 스레드·IG 예약 발행 | 공식 API 기반 자동 게시 | 앱 심사 + 레이트리밋 준수 |
| 댓글→DM 자동 발송 | '링크' 댓글에 자동 DM | 공식 API(private reply) 또는 공식 파트너 SaaS만 |
| 통합 대시보드 | 채널별·상품별 성과 한 화면 | API 없는 곳은 정산 CSV 파싱 |

### B. AI가 초안, 사람이 승인

- **훅 카피 생성** — 기존 카톡/스레드 메시지 수백 개가 스타일 코퍼스. 현표 말투로 초안
- **취향 스코어링** — 발행/스킵 이력 학습 → 후보 큐 상단 정렬
- **유튜브 메타** — 제목·썸네일 카피·설명란·고정댓글·챕터 초안, 쇼츠 컷 포인트 제안
- **CS 답변 초안** — 168/62 착용감 DB 기반 사이즈 FAQ, 재입고·쿠폰 안내
- **협찬 운영** — 문의 1차 정리, 조건 요약, 브리프·성과 리포트 초안
- **주간 요약** — "이번 주 살 만한 것" 스레드/뉴스레터 초안

### C. 사람이 계속 하는 것 (도구는 보조만)

- **최종 "올릴지 말지" 판단** — 이 채널의 자산은 취향과 신뢰. 자동 추천이 몇 번 틀리면 즉시 훼손
- **촬영·착장, 브랜드 관계·협상의 최종 결정**
- **카톡 오픈채팅의 '전송' 버튼** — 카카오는 오픈채팅 API를 제공하지 않으며,
  비공식 봇은 운영정책 위반으로 계정 정지 위험. 반자동(완성본 전달 → 원탭 전송)이 유일한 안전선

## 4. 제약 조건 (설계를 지배하는 규칙)

1. **계정 보호 최우선** — 상세는 [03-account-safety.md](03-account-safety.md).
   요약: 계정에 연결되는 것은 공식 API뿐. 공식 API가 없는 채널은 반자동.
   수집은 계정·기기·IP에서 완전 격리. 비공식 봇·세션 자동화·비밀번호 공유는 어떤 경우에도 금지.
2. **공정위 표시광고** — 커미션 링크에는 경제적 이해관계 고지를 시스템이 자동 삽입.
   사람이 깜빡할 수 있는 것을 시스템이 보증한다.
3. **무신사 큐레이터 운영정책** — 링크 남용·크롤링 남용 금지 조항 준수.
   병행 트랙으로 무신사와의 공식 제휴/데이터 협의 추진.
4. **실사용성** — 매일 3시간 → 10~30분이 실제로 달성돼야 함.
   승인 1건 = 30초 이내. 도구가 채널 하나 늘리는 부담이 되는 순간 실패.

## 5. 성공 지표

| 지표 | 현재 | Phase 2 (6주) | Phase 4 (14주) |
|---|---|---|---|
| 딜 1건 발행 소요 시간 (발굴→4채널) | 30~60분 | ≤ 8분 | **3~5분** |
| 일일 반복 작업 시간 | ~3시간 | **60~75분** (60~75% 절감) | **25~35분** (80~85% 절감) |
| '링크' 댓글 응대 | 수동, 건당 수 분 | 반자동 | 자동 링크 카드 (권한 실측 통과 시) |
| 죽은 링크 방치 기간 | 무기한 | ≤ 24시간 감지·표시 | ≤ 6시간 (활성 딜) |
| 성과 파악 | 4개 대시보드 수동 취합 | — | 1개 화면, 상품·채널별 |
| **계정 경고/제재 건수** | 0 | **0** | **0 (절대 유지)** |

> 시간 수치는 하루 시뮬레이션 검증을 거친 정직한 계산이다([04-roadmap.md](04-roadmap.md) §0).
> 잔여 시간의 최대 항목은 무신사 큐레이터센터 링크 수동 생성(API 부재)이며,
> 무신사 공식 제휴가 성사되면 10분대가 열린다.

## 6. 확장 전제

이 스택은 현표 1명용으로 시작하지만, 동일한 문제를 가진 **무신사 활성 큐레이터 4,400명**에게
그대로 적용 가능한 구조다. 1차 목표는 현표를 레퍼런스 유저로 완성하는 것이며,
멀티테넌트 확장은 데이터 모델에서 `user_id` 격리만 미리 깔아두고 그 외에는 미루는 것을 원칙으로 한다
(조기 범용화가 1인 사용자의 실사용성을 해치는 것을 경계).
